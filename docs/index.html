ABOUT

BazzBasic is a BASIC interpreter for Windows x64, built with .NET 10 and SDL2.

It is built around one idea: learning to program should be easy and fun.

The spirit of the classic BASICs, with modern features and a fresh feel.

Free and open source under the MIT License.

SWISS ARMY KNIFE

One small tool, many uses. Write an old-school text adventure, a graphical game, or a program that uses a game controller, the mouse or the network.

Need more? With SHELL, BazzBasic can drive any command-line tool — from an SQLite database to your own scripts.

See what's possible in the Gallery.

BEGINNER FRIENDLY

Download, extract, run BazzBasic.exe.
That's it.

No installer, no dependency hell.

Simple syntax lets you write your first small game in an evening or two. Browse the short example programs to see for yourself.

Give this SKILL.md to your favorite AI assistant and it can teach you BazzBasic right away.

STORY

Over the years I have moved on to more versatile and modern languages, but BASIC has always stayed fun. Sometimes it's simply great to write a small adventure game, a lottery machine, a quiz, or just a few balls bouncing around the screen.

BazzBasic was created with exactly that in mind: a language that lets you sit down and program something, without first fighting your tools.

And when you finish your first little game, you may start craving something bigger. Maybe one day you will move on to another language. If you do, BazzBasic has done exactly what it was made for.

To release your curiosity.

— Kristian Virtanen (EkBass) —
